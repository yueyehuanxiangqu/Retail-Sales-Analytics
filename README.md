# Retail Sales Analytics

A small project to practice data processing and analysis with Databricks, PySpark, Spark SQL, and Delta Lake.

The project uses the [Store Sales - Time Series Forecasting](https://www.kaggle.com/competitions/store-sales-time-series-forecasting) dataset from Kaggle.

## Tools

- Python / PySpark
- Databricks
- Spark SQL
- Delta Lake

## Progress

- **Data Loading:** Imported and explored the sales, stores, transactions, holidays, and oil price datasets.
- **Data Cleaning:** Checked missing values, duplicates, and basic data consistency. Added date features, filled missing oil prices where possible, and saved the processed data as Delta tables.

## Next Steps

- Analyze sales patterns using Spark SQL.
- Compare sales across stores and product categories.
- Explore basic sales forecasting.

## Data

The original dataset is available on Kaggle and is not included in this repository.
